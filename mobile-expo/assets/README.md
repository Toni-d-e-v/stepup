# Assets Directory

Place your app icons and splash screens here.

## Required Files

- `icon.png` - 1024x1024px app icon
- `splash.png` - 1242x2436px splash screen
- `adaptive-icon.png` - 1024x1024px Android adaptive icon
- `favicon.png` - 48x48px web favicon

## Quick Setup

For development, you can use placeholder images or generate them using:
- https://www.figma.com (design tool)
- https://www.canva.com (quick graphics)
- https://icon.kitchen (icon generator)

## Icon Guidelines

**App Icon:**
- 1024x1024px
- PNG format
- No transparency (solid background)
- Simple, recognizable design

**Splash Screen:**
- 1242x2436px (or higher)
- PNG format
- Match your app theme
- Background color: `#6200ee` (primary purple)

## Temporary Solution

If you need to test without custom assets:
1. Use any 1024x1024 image as `icon.png`
2. Use any 1242x2436 image as `splash.png`
3. The app will work fine with default/placeholder images
